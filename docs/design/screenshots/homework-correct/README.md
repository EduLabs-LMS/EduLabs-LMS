# Homework correcting screenshots

Synthetic harness data (scripts/homework-correct-browser.cjs): the real screens, middleware and CSS, a fictional server checked against the real contract and reply mapper. Light theme; desktop 1360 and phone 390; Classic and New; English and Arabic (right to left). File names: `<screen>-<size>-<look>-<language>.png`.

- correct-choice-essay-photo: one student, the choice summary (right or wrong with the letters), the essay with the photo exactly as sent, a mark being given
- correct-photo-deleted: a photo deleted to free space ("Image deleted to free space")
- correct-missed-deadline: a try handed in after the deadline (desktop)
- correct-release-confirm: "Release N grades" confirm, saying students are notified
- correct-release-changed: a grade changed elsewhere, nothing released, Reload (desktop)
- correct-stale: a save refused because the try changed elsewhere; what was typed is kept and Reload is offered
- correct-released-reason: changing a released grade asks for a reason (desktop)
- correct-list: the student list on a phone
- correct-done-tab: the Done tab (desktop)
- home-card: Home with "Homework to correct"
- student-lesson-no-parts: the student lesson page for a lesson with no part, its homework below
- student-try-again: handed in, deadline and tries left, Try again
- student-missed-deadline: handed in late, "Missed the deadline", no tries left
- student-kept-answer: after Try again, the kept answer is locked (desktop)
- student-refused: Try again refused, said plainly in the page language (desktop)

The student pictures show the existing student styles inside a plain page (no student sidebar); they were not restyled.
